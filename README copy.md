# Achilles

Workout tracker for custom programs

## Usgae

This is really intended for the user-end rather than a program designer - but changing the program in there right now to anoth program should be fairly straightforward and all app functionality will stay the same. 

The app should be pretty intuitive, logging a day moves you to the next day in the cycle, your lifts are tracked and showed to you for the next time you're on that day. 

There are simple plots for body measurements and lifts to show progress over time.

You can also set goals for Personal Bests, and current maxes, and the strength tab will show your progress there. There's also a Big 3 total in the top right - so if you change the program and remove the bench, squat, deadlift element - that might throw an error?

Overall - pretty simple, I haven't found an off-the-shelf tool that felt customizable, so I figured I'd make it. 
A lot of this code is AI-generated since I'm a bit sapped on time, but if you have any questions about anything I'll be able to help.
